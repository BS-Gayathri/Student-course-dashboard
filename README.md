# Student Course Dashboard | Power BI

## Project Overview
This project presents an interactive Power BI dashboard designed to analyze student enrollment, course distribution, fee information, student demographics, and certificate issuance.

## Tools Used
- Microsoft Power BI
- Power Query
- Microsoft Excel

## Data Preparation
- Imported the student dataset into Power Query.
- Cleaned and transformed the data.
- Corrected data errors and prepared the dataset for analysis.
- Built interactive visualizations in Power BI.

## Dashboard Analysis
The dashboard explores:
- Student enrollment trends by month
- Fee distribution by course
- Student distribution by course and city
- Certificate issuance
- Student age-group distribution

## Project Objective
To transform raw student data into an interactive dashboard that supports clear and effective analysis of student and course-related information.
